## Manual review of automated findings

The raw score is **not a reliable measure of this site's readiness or exposure**. Findings were reviewed rather than automatically applied:

| Tool finding | Evidence and decision |
| --- | --- |
| Invalid sitemap XML | False positive: direct HTTP returned 200 with valid XML and 53 URL entries before changes. The tool's HTTP connector exposes an empty `html` field for non-HTML responses, and the crawler analyses that empty field. |
| Missing Sitemap declaration in robots.txt | Same connector problem. The live file contains `Sitemap: https://rankoff.my/sitemap.xml`. |
| Invalid hreflang | The affected code is `zh-Hans`, a script-specific language tag. Do not replace the site's language architecture to satisfy the tool's narrower regex. |
| Duplicate titles | Reported URLs include fragments and filters on the same canonical page. No evidence in this finding of separate canonical merchant pages sharing titles. |
| Five HTTP errors | Cloudflare `/cdn-cgi/l/email-protection#...` utility links, not merchant pages. These do not establish broken merchant URLs. |
| Image dimensions | Static hint; merchant logo containers already reserve dimensions. Requires measured layout evidence before changing layouts. |
| Blocking scripts | Theme/locale boot scripts intentionally run before painting. No evidence from this static hint that deferring them improves the experience. |
